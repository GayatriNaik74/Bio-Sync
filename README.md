# Bio-Sync: A Dual-Mode Framework for Continuous Authentication via Behavioral Biometrics and Blockchain Technology

Bio-Sync is a cybersecurity framework designed to provide continuous identity verification using behavioral biometrics and blockchain technology. Unlike traditional authentication systems that verify users only during login, Bio-Sync continuously monitors user behavior throughout the session to detect unauthorized access, session hijacking, and identity fraud.

The system combines Machine Learning, Explainable AI (XAI), and Blockchain to create a secure, transparent, and tamper-resistant authentication framework.

#Features

1.Continuous Authentication
- Monitors user behavior throughout the session.
- Eliminates the "trust-once" vulnerability of traditional authentication systems.

2.Behavioral Biometrics
- Keystroke Dynamics
- Mouse Movement Analysis
- Typing Rhythm Monitoring
- User Behavioral Profiling

3.AI-Based Intrusion Detection
- Real-time anomaly detection.
- Dynamic trust score generation.
- Risk classification (Low, Medium, High).

4.Explainable AI (SHAP)
- Visual explanation of AI decisions.
- Transparent intrusion detection process.

5.Blockchain Security
- Tamper-proof audit logs.
- Immutable authentication records.
- Smart contract-based security actions.

6.Admin Dashboard
- Multi-user monitoring.
- Intrusion analysis.
- Trust score visualization.
- Blockchain event tracking.
